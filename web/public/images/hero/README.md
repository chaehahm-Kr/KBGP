# 히어로 이미지 슬롯

이 디렉토리에 파일을 넣고 [`lib/hero-media.ts`](../../../lib/hero-media.ts) 의
`src` 를 `null` 에서 경로로 바꾸면 교체가 끝난다. 컴포넌트는 수정하지 않는다.

| 슬롯 | 파일명 | 비율 | 최소 해상도 | 내용 |
|---|---|---|---|---|
| A | `store-exterior.jpg` | 4:3 | 장변 2400px 이상 | 미국 현지 Beauty Supply 매장 **외관** |
| B | `store-in-store.jpg` | 1:1 | 장변 2400px 이상 | 매장 안 K-Beauty 전용 **Store-in-a-Store 진열대** |

## 요구사항

- **비율을 미리 잘라서 넣는다.** 프레임이 `object-cover` 로 잘라내므로 중심
  피사체가 프레임 밖으로 밀리지 않게 사전 크롭한다.
- 파일 형식은 `.jpg` 또는 `.webp`. 용량은 장당 500KB 이하를 권장한다.
- **스톡 사진을 쓰지 않는다.** 실제 운영 매장을 직접 촬영한 사진만 쓴다
  (`DESIGN.md` §7). 웃는 모델, 악수, AI 생성 렌더는 금지다.
- 사진이 어두우면 하단 캡션 띠와 대비가 떨어질 수 있다. 캡션은 `paper`
  배경 위에 올라가므로 문제는 없지만, 하단 20% 영역에 핵심 피사체를 두지
  않는 편이 좋다.

## blur 플레이스홀더 (선택)

`HeroFrame` 은 `blurDataURL` 이 있을 때만 `placeholder="blur"` 를 켠다.
런타임 문자열 `src` 에 `blurDataURL` 없이 blur 를 켜면 Next 가 예외를
던지므로, 필요하면 base64 문자열을 함께 넘긴다.

## 사진이 없는 동안

`src: null` 이면 대각선 스트라이프 대신 계산된 SVG 도식이 렌더된다.

- 슬롯 A → 매장 네트워크 지도 (현재 거점 채운 원 / 확장 예정 링)
- 슬롯 B → 매대 선반 도식 (전용 구획 한 칸만 액센트)

두 폴백 모두 `role="img"` 와 `aria-label` 을 가지므로 접근성상 빈 칸으로
읽히지 않는다.
