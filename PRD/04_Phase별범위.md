# 나누는 기준

"한 번에 모두 개발하지 않는다"는 원칙에 따라, **거래의 자연스러운 분기점**을 기준으로 나눴습니다.

- Phase 1 = 이 회사가 파트너가 될 자격이 있는가를 판단하는 단계 (돈이 오가지 않음)
- Phase 2 = 파트너십 조건을 확정하는 단계 (계약과 발주, 아직 물건은 안 움직임)
- Phase 3 = 실제로 물건이 만들어지고 미국까지 이동하는 단계 + 미국 리테일러 확장

# Phase 1 — 신청 접수와 심사 (MVP)

**목표:** 브랜드사가 온라인으로 회사·제품 정보를 등록하고 신청서를 제출하면, Letusto 담당자가 시스템 안에서 심사해 결과를 통보할 수 있다.

## 포함 기능

- 회사 회원가입 및 로그인
- 회사별 여러 사용자 등록 (Company Admin이 Staff 초대)
- 회사 프로필 관리
- 브랜드 관리 (등록/수정)
- 제품 등록 및 수정
- 제품 이미지와 인증서 업로드
- 참가 신청서 제출 (제품 1개 이상 선택)
- 신청 상태 확인 (회사 측)
- 관리자 심사 (신청서 단위 + 제품 단위, 서로 독립)
- 추가 자료 요청
- 내부 메모
- 담당자 배정
- 이메일 알림 (기본 이벤트: 제출 확인, 추가자료 요청, 심사 결과)
- 관리자 대시보드 (기본: 신청 목록, 상태별 필터, 담당자별 필터)
- 직원 계정 및 역할 기반 권한 구조 (역할은 다 만들되, Phase 1에서 실제 쓰는 건 Reviewer와 Super Admin)

## 명시적으로 제외

- 상담 미팅 예약 (Phase 2)
- 회사-Letusto 메시지 기능 (Phase 2 — Phase 1에서는 "추가 자료 요청"이라는 단방향에 가까운 기능으로 최소한의 소통만 지원)
- 샘플, 견적, 계약서, PO (Phase 2)
- 생산·검사·배송 상태 (Phase 3)
- 결제 상태 (Phase 3)
- 미국 리테일러 포털 (Phase 3)

> **메시지 기능을 Phase 1에서 뺀 이유:** 자유 대화형 메시지는 UI와 알림 설계가 생각보다 크고, Phase 1의 핵심 목표(심사 프로세스 디지털화)에 필수가 아닙니다. "추가 자료 요청 → 회사가 파일 첨부해 회신"이라는 제한된 형태로 최소 기능만 Phase 1에 넣고, 자유 대화는 Phase 2에서 다룹니다.

## Phase 1 완료 조건 (이걸 만족하면 Phase 1은 끝난 것)

- 실제 브랜드사 담당자가 도움 없이 회원가입부터 신청서 제출까지 혼자 완료할 수 있다
- Letusto 담당자가 엑셀을 열지 않고도 오늘 들어온 신청을 확인·배정·심사할 수 있다
- 신청 결과(승인/보류/반려)가 이메일로 자동 통보된다
- 최소 1건의 실제 신청이 이 시스템을 통해 접수부터 심사 결과까지 완주한다

# Phase 2 — 파트너십 성사 (샘플 → 견적 → 계약 → PO)

**목표:** 심사를 통과한 제품에 대해 실제 거래 조건을 확정하고 발주(PO)까지 시스템 안에서 처리한다.

## 포함 기능

- 상담 예약 (Microsoft Bookings 연동 — `00_INDEX.md`의 확인 필요 항목 참고)
- 회사-Letusto 메시지 (신청서별 또는 제품별 대화 스레드, 첨부파일 지원)
- 샘플 요청 및 수령 관리, 제품 평가
- 견적 요청 및 비교
- 계약서 관리 (업로드·상태 추적. 전자서명 연동은 Phase 3 검토 대상)
- PO 작성, 내부 승인, PDF 발행, 이메일 전송
- 공급사(브랜드사)의 PO 확인/승인
- 이메일 알림 확장 (샘플 발송, 견적 발송, PO 발행 등)

## 명시적으로 제외

- 생산·검사·출고·배송 상태 추적 (Phase 3)
- 미국 리테일러 포털 (Phase 3)

## Phase 2 착수 전 확인할 것

Phase 1을 실제로 운영해보고 나서 아래를 다시 점검한 후 Phase 2 상세 기획(화면 단위 AC 등)을 진행하는 것을 권장합니다.

- Phase 1에서 실제로 얼마나 많은 신청이 들어왔고, 심사 기준이 실제로 잘 작동했는가
- 미팅 예약 도구를 Microsoft Bookings로 확정할지 재확인
- 계약서 전자서명이 정말 필요한지, 그냥 PDF 업로드 확인 수준으로 충분한지

# Phase 3 — 이행 관리와 미국 리테일러 확장

**목표:** PO 확정 이후 생산부터 미국 입고까지의 흐름을 추적하고, 향후 미국 Beauty Supply 매장이 직접 시스템을 사용할 수 있게 한다.

## 포함 기능

- 생산, 검사, 출고, 선적, 배송 상태 관리
- Invoice, Packing List, BOL 등 문서 관리
- 결제 상태 관리 (기록만, 실제 결제 연동 없음)
- 관리자 대시보드 고도화 (전체 파이프라인 뷰, 지연 알림 등)
- 직원별 권한 관리 심화 (조직이 커졌을 경우 Account Manager/Operations 역할 실제 분리 운영)
- 변경 이력과 활동 로그 전면화
- (신규) 미국 Retailer 포털: 회원가입/로그인, 카탈로그 열람, 디스플레이 신청, 주문·재주문, 교환 요청, 메시지, 인보이스 확인

## 명시적으로 제외 (Phase 3 이후로 미룸)

- 실시간 결제 게이트웨이 연동
- 다국어 완전 지원(리테일러 포털의 스페인어 지원 등 — 필요시 별도 논의)
- 재고관리(WMS) 수준의 상세 창고 관리

# Phase 비교 요약표

| 구분 | Phase 1 | Phase 2 | Phase 3 |
|---|---|---|---|
| 핵심 질문 | 이 회사와 거래해도 되는가? | 어떤 조건으로 거래할 것인가? | 실제로 물건이 잘 가고 있는가? |
| 돈의 흐름 | 없음 | 계약·PO(약속) | 실제 결제 상태 기록 |
| 주 사용자 | 회사 담당자, 심사 담당 | 회사 담당자, 영업 담당 | 회사 담당자, 운영 담당, (신규)리테일러 |
| 신규 상태값 | 신청 상태, 제품 심사 상태 | 샘플 상태, 견적 상태, PO 상태 | 주문·배송 상태 |
| 이 문서 세트에서의 상세도 | 화면 단위 AC까지 (`08` 문서) | 기능 목록 수준 | 기능 목록 수준 |
